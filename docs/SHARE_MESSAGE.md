# 短视频简介与转发文案

## 短视频简介（可直接复制）

我给孩子做了一个中文学习 App：China Quest「我的中国远征」，现在也分享给有需要的家庭。

认汉字、点按听发音、读常用词，还能给汉字涂色、参与开关门和吃苹果的小情景。家长可以跳过孩子已经认识的字，两个孩子分别记录进度。

📱 安卓手机、平板可下载安装（Android 8.0+），不需要专门的学习设备。
📖 离线使用，无需注册，没有广告。学一点，再去纸上写、生活里用。

介绍、下载和安装步骤：
https://github.com/leslietan19000/china-quest

目前是家庭试用版，暂不支持 iPhone / iPad。欢迎试用后告诉我哪里可以改进。

## 置顶评论：怎么安装

用安卓手机或平板打开项目主页，点「下载 Android APK」，下载后在文件管理器中打开安装；不需要下载源码，也不用编译。首次使用由家长设置 PIN，再选择孩子开始。
