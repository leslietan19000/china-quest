# 可转发给朋友的介绍

最近做了一个给家庭使用的中文学习 Android 试用版 China Quest。它可以离线学习汉字和常用词，点按听合成语音，也可以给汉字涂色、玩几个自己点按推进的小情景。

项目主页：https://github.com/leslietan19000/china-quest

安装说明：https://github.com/leslietan19000/china-quest/blob/v0.3.0-preview/docs/INSTALL.md

下载页：https://github.com/leslietan19000/china-quest/releases/tag/v0.3.0-preview

这是 Android 8.0 及以上的家庭试用预览版，目标设备是 BOOX Nova Air C；这个版本还没有完成 BOOX 实机验收，也没有 iOS 版本。学习记录和作品保存在当前设备，没有账号、云同步或完整备份。已经安装旧版的话，请覆盖更新，不要卸载或清除数据。
