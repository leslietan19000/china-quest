# 短视频简介与转发文案

## 短视频简介（可直接复制）

在海外养两个娃，中文一直是我很挂心的事。我希望他们即使在国外长大，也不只是会说几句中文，还能认字、读中文、动笔写汉字。

所以我给两个娃做了一个中文学习 App：China Quest「我的中国远征」。可以认汉字、点按听发音、读词语，也能涂色、参与小情景，再配合纸笔练习，把学过的字真正写下来。

这不是做完就放着的项目。我会根据两个娃的想法和使用情况，持续增加、修改一些功能，让他们也参与设计自己用的学习工具。

如果你也在海外，为孩子的中文学习发愁，欢迎下载试一试。有哪里不好用、想增加什么功能，都可以提出来，我会结合孩子们的实际需要继续改进。

📱 安卓手机、平板可安装（Android 8.0+），暂不支持 iPhone / iPad。
📖 离线使用，无需注册，没有广告。目前是家庭试用版。

介绍、下载和安装步骤：
https://github.com/leslietan19000/china-quest

## 置顶评论：怎么安装

用安卓手机或平板打开项目主页，点「下载 Android APK」，下载后在文件管理器中打开安装；不需要下载源码，也不用编译。首次使用由家长设置 PIN，再选择孩子开始。
