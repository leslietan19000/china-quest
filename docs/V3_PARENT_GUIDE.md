# 第三版试用：孩子提出，孩子来试

当前版本：`0.3.0-preview`。基于第二版，加入孩子提出的涂色与互动情景。第二版的基础筛选、常用词和离线声音仍然保留。

## 更新并保留进度

把 `artifacts/ChinaQuest-0.3.0-preview.apk` 复制到 BOOX，打开并选择更新。**覆盖安装，不要卸载或清除数据。** 包名和签名沿用之前的试用版，原 PIN、学习记录、掌握度、印章和正在进行的课程保留。涂色作品存入单独的本机数据库。

这个版本用于家庭试用；代码保留在 `kid/family/color-scenes` 分支，尚未合并到主分支。它可以覆盖更新既有安装。旧 APK 保留在电脑，但 Android 通常不允许直接降版本；不要为了退回旧版本而卸载，若遇问题应修复为更高版本继续覆盖更新。

## 给汉字涂颜色

选择孩子 → 今天 → **创作小工坊** → **给汉字涂颜色**。字表按页展示，可以选择现有 178 字中的一个。学新字时也有 **涂这个字** 入口，返回后继续原来的课程。

先选红、黄、蓝、绿、紫、黑中的一种，再点字的笔画填色；也可以选择 **画笔涂色**，用手指或笔慢慢涂。颜色被限制在字的形状内，黑色轮廓始终保留。点按填色会换整个字的底色，画笔可以在同一个字上画不同颜色。

每次手指或笔抬起后自动保存。**撤回一笔** 可以撤回画笔、填色，也可以撤回 **重新涂**。同一个孩子再次打开同一个字，会看到自己的作品；另一个孩子分别保存。作品只在这台设备，家长报告不是作品备份。涂色不判断写字对错，也不替代纸笔写字。

画布有动作数量上限，达到后会提示，可撤回几笔或换一个字，既有作品不会被偷偷清空。墨水屏颜色可能比较柔和；画笔刷新慢时可用默认的点按填色。

如果提示没存成功，返回操作会先重试；仍然失败时会保留当前画面，避免默默丢掉作品。请家长检查设备剩余空间后再返回。尚未写入磁盘的画面并非可靠备份，不要强制停止、清除应用数据或关机来处理这个提示。

## 点一下，让小情景变化

工坊第一批有六个字，对应三类情景：

- **口、吃**：拿起苹果 → 送到嘴边 → 咬一口。
- **开、关**：点门把手，逐步开门或关门，看看门后的熊猫。
- **水、喝**：拿起水杯 → 喝一口水。

可以点图中的苹果、嘴、门把手或水杯，也可以按下方大按钮。画面只在孩子操作后变化，2–3步就到一个停点；不会自己播放、自动循环或跳入下一项。中途退出会记住该孩子上次的步骤。每页都有点按听这个字的离线声音。

这些图帮助理解字的生活用法，不是汉字起源解释或自动测试。试完可以离开屏幕：指一指自己的嘴，和家长轻轻开关门，或用“水”说一句话。无需把六项全做完，也不为凑满分钟而延长使用。

## 请孩子判断这个版本

涂色和情景页下方都有 **喜欢，保留 / 想改一改 / 不喜欢**。任何选择都不会影响印章、奖励或学习进度，也不会自动改软件。家长输入原 PIN 后，可以在本机家长空间看到每个孩子的反馈。孩子可以改主意。

本次只实现这个反馈闭环的试用部分，尚无儿童语音提案、AI 自动编程、自动合并或发布。

## 真机试用时留意

软件检查不替代 BOOX 真机观察。重点看颜色能否辨认、画笔是否顺手、滚动时是否误画、待机唤醒后是否保留作品。原有声音为合成语音，实际音量需在设备上试听。涂色和情景不需要网络。
