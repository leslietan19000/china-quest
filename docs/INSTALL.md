# China Quest 0.3.0-preview 安装说明

China Quest 是给家庭使用的离线中文学习试用版。项目主页：[GitHub 项目](https://github.com/leslietan19000/china-quest)。

## 下载

请从 [v0.3.0-preview 发布页](https://github.com/leslietan19000/china-quest/releases/tag/v0.3.0-preview) 下载 APK，也可直接下载 [ChinaQuest-0.3.0-preview.apk](https://github.com/leslietan19000/china-quest/releases/download/v0.3.0-preview/ChinaQuest-0.3.0-preview.apk) 和 [SHA-256 校验文件](https://github.com/leslietan19000/china-quest/releases/download/v0.3.0-preview/ChinaQuest-0.3.0-preview.apk.sha256)。下载后可用本机的 SHA-256 工具核对 APK 与校验文件中的摘要一致。

## 设备与安装

使用 Android 8.0（API 26）及以上的安卓手机或平板即可下载安装，不需要墨水屏或专用学习机。暂不支持 iPhone / iPad。当前是试用版，尚未覆盖所有机型实测；如遇显示或触控问题，欢迎反馈设备型号。

将 APK 下载到设备，在文件管理器中打开并按提示安装。如果系统要求，允许当前文件管理器安装未知来源应用；安装后可关闭该权限。首次打开时由家长设置一个 6–12 位数字 PIN。应用内置两个独立的孩子档案，可由家长修改称呼，各自保存学习记录、起点设置和创作内容；请勿在公开分享时填写真实姓名等可识别信息。

## 更新与使用

已经安装 China Quest 旧版的家庭，请直接安装新版覆盖更新，并使用原来的家长 PIN。**不要先卸载应用，也不要清除应用数据**，否则本机学习进度和档案可能丢失。

家长可以分别为每个孩子筛选已经认识的字；所选字会从后续尚未开始的新课程中跳过。应用包括 178 个汉字、常用词、离线合成语音、汉字涂色和六个可点按推进的小情景。孩子可以在本机保存涂色与情景进度。

这是家庭试用预览版，使用开发签名。不同安卓机型的实际体验可能不同。应用数据只保存在当前设备：没有账号或云同步，也没有可恢复完整数据的备份功能。请家长陪同安装和使用，并先阅读 [版本说明](https://github.com/leslietan19000/china-quest/blob/preview/docs/RELEASE_0.3.0.md)。

## 如果你使用墨水屏

墨水屏是可选设备，不是使用前提。项目最初在家庭的 BOOX 上使用；新版的颜色、画笔延迟与残影仍需实机反馈。普通安卓手机和平板无需使用墨水屏设置。
